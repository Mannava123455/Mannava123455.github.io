# Venkatasai Mannava — Personal Portfolio

A responsive GitHub Pages portfolio for Venkatasai Mannava.

## Files

- `index.html` — main website
- `css/style.css` — styling and responsive layout
- `js/script.js` — navigation and scroll animations
- `resume.pdf` — add your final resume PDF here

## Publish on GitHub Pages

1. Create a GitHub repository named `<your-github-username>.github.io`.
2. Upload `index.html`, the `css` folder, the `js` folder and `resume.pdf`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the deployment.
7. Visit `https://<your-github-username>.github.io`.

## Before publishing

Replace the placeholder GitHub and LinkedIn URLs in `index.html` with your actual profiles.

The website content is based on the supplied resume. The `resume.pdf` file is intentionally not duplicated here; place your preferred final PDF in the website root.
